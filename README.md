# TalentBridge HR Recruitment Automation

> An end-to-end recruitment workflow built using **Google Forms, Google Sheets, Gmail, Trello, Google Calendar, and Zapier** to automate candidate intake, communication, interview management, and employee onboarding.

---

## Project Overview

TalentBridge HR Recruitment Automation is a no-code Applicant Tracking System (ATS) designed to streamline the recruitment lifecycle.

The solution eliminates repetitive administrative work by automatically collecting applications, acknowledging candidates, creating recruitment records, and managing applicants through the hiring pipeline.

# Business Scenario

A growing recruitment agency receives dozens of applications daily.

Recruiters previously had to:

- Review every application manually
- Copy applicant information into Trello
- Send confirmation emails individually
- Track recruitment progress manually
- Maintain multiple spreadsheets

The objective was to automate these repetitive processes while improving candidate experience and recruiter productivity.

---

# Solution

The solution combines several no-code platforms into one automated recruitment workflow.

| Platform | Purpose |
|----------|----------|
| Google Forms | Candidate application form |
| Google Sheets | Recruitment database |
| Gmail | Confirmation emails |
| Trello | Applicant Tracking System |
| Google Calendar | Interview scheduling |
| Zapier | Workflow automation |
