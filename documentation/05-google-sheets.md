# Google Sheets Integration

## Objective

Google Sheets serves as the central data repository for all recruitment applications submitted through the TalentBridge HR Job Application Form.

Each form submission is automatically recorded in Google Sheets, providing HR with a structured database of all applicants.

---

# Purpose

The spreadsheet acts as the single source of truth for candidate information before it is processed by downstream automations.

---

# Data Captured

The spreadsheet stores the following information for every applicant:

- Timestamp
- Full Name
- Email Address
- Phone Number
- Position Applied For
- Years of Experience
- Preferred Work Arrangement
- Available Start Date
- Resume Link
- Candidate Summary

---

# Integration

Google Sheets receives new records automatically whenever a candidate submits the Google Form.

Zapier monitors the spreadsheet for new responses and initiates the recruitment workflow.

---

# Benefits

- Automatic data collection
- Eliminates manual data entry
- Creates a searchable recruitment database
- Provides a backup of all candidate submissions
- Supports reporting and recruitment analytics

---

# Business Value

Using Google Sheets as the recruitment database ensures that every application is securely stored while allowing recruitment workflows to scale without additional administrative effort.
