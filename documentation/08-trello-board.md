# Trello Recruitment Board

## Objective

Trello was configured as a lightweight Applicant Tracking System (ATS) to manage candidates throughout the recruitment lifecycle.

Each candidate is automatically added to the recruitment board after submitting a successful application.

---

# Board Purpose

The recruitment board provides recruiters with a centralized workspace for tracking candidates from application through hiring.

It replaces manual spreadsheets and provides clear visibility into every recruitment stage.

---

# Recruitment Pipeline

The board consists of the following recruitment stages:

- New Applications
- Phone Screening
- Interview Scheduled
- Interviewed
- Offer Sent
- Hired

Each list represents a stage in the recruitment process.

---

# Card Structure

Each candidate card contains:

- Full Name
- Position Applied For
- Email Address
- Phone Number
- Years of Experience
- Preferred Work Arrangement
- Available Start Date
- Resume Link
- Candidate Summary

This ensures recruiters have all essential candidate information in a single location.

---

# Automation Integration

Zapier automatically:

- Creates a new Trello card
- Populates candidate details
- Updates candidate information
- Supports downstream recruitment automations

Recruiters simply move cards between lists as candidates progress through the hiring process.

---

# Business Benefits

- Centralized applicant tracking
- Improved recruitment visibility
- Reduced manual administration
- Better collaboration between recruiters
- Standardized recruitment workflow

---

# Outcome

The Trello board functions as a simple Applicant Tracking System, allowing recruiters to manage candidate progression using an intuitive Kanban workflow.
