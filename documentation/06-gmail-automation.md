# Gmail Automation

## Objective

The Gmail automation provides immediate confirmation to candidates after they successfully submit a job application.

This improves the candidate experience by acknowledging receipt of the application without requiring manual intervention from the recruitment team.

---

# Automation Trigger

**Trigger**

Google Form Submission

Whenever a candidate submits the TalentBridge HR Job Application Form, Zapier automatically initiates the email workflow.

---

# Automated Actions

The automation performs the following tasks:

- Retrieves candidate information from Google Forms
- Personalizes the email using dynamic fields
- Sends a confirmation email to the applicant
- Confirms successful receipt of the application

---

# Dynamic Information Used

The confirmation email includes:

- Candidate Name
- Position Applied For
- Years of Experience
- Preferred Work Arrangement
- Available Start Date

Dynamic fields ensure every applicant receives a personalized acknowledgement.

---

# Business Benefits

- Instant communication with applicants
- Improved candidate experience
- Reduced recruiter workload
- Consistent messaging
- Eliminates manual confirmation emails

---

# Outcome

Every submitted application automatically generates a personalized confirmation email, ensuring candidates know their application has been successfully received.
